# Team Contribution Guide

This package is an integrated starting point. Each person should make, test and commit their own genuine changes to their assigned module using their own GitHub account and Jira issue. Do not all upload the finished package as separate claimed individual work.

## Suggested Jira mapping
- SCRUM-5: Homepage & Navigation — `index.html`
- SCRUM-6: Product Catalogue & Product Details — `catalog.html`, `product-detail.html`, product rendering/search/filter code
- SCRUM-7: Registration & Login — `login.html`, authentication code
- SCRUM-8: Shopping Cart / Checkout — `cart.html`, `checkout.html`, `confirmation.html`, cart/checkout code

## Integration
Use one shared repository. Each member commits their own module. Merge/test the integrated website before the Sprint Review.
